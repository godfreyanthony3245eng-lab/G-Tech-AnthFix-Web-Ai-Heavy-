# GT-AnthoFix AI (G'sTAF V3.0.3256)

> A personal, single-file AI web interface engineered for real-time text streaming, isolated code execution containers, interactive HTML data table exports, and student academic tools.

---

## 🌟 Key Features

* **Single-File Architecture:** Fully self-contained client-side web application running entirely within one HTML file for effortless static hosting on GitHub Pages.
* **Dynamic Response Streaming:** Smooth, word-by-word fade-in text rendering paired with custom markdown parsing and syntax highlighting.
* **Isolated Code & Table Engine:** 
  * Automatically isolates code blocks into dedicated containers with copy controls.
  * Formats tabular data into interactive HTML tables with instant **PDF**, **CSV**, and **HTML** file downloads.
* **Multi-Mode Context System:**
  * **Customer Support Mode:** Professional, concise assistant for general queries.
  * **Student / Learner Studio:** Step-by-step academic breakdowns for STEM, Physics, Chemistry, Economics, and Coding.
  * **Employees / Repair Diagnostics:** Hardware troubleshooting, component testing protocols, and pinout diagrams.
* **Student OCR Camera Scanner:** Integrated mobile camera capture powered by `Tesseract.js` for scanning textbook questions directly into the AI prompt.
* **Voice Integration & Speech Synthesis:** Built-in Web Speech API supporting hands-free voice recognition input and dynamic text-to-speech output.
* **Responsive Light/Dark UI:** Adaptive theme system with toast notifications, pinned message history, and desktop/mobile support.

---

## 🚀 Deployment & Usage

This project requires zero build tools, node packages, or complex deployment steps.

1. Clone or download the `index.html` file.
2. Open `index.html` directly in any standard modern mobile or desktop web browser.
3. Host instantly for free via **GitHub Pages** by setting the deployment branch to `main`.

---

## 🛠 Tech Stack

* **Frontend:** HTML5, CSS3 (CSS Variables, Responsive Flexbox/Grid), JavaScript (ES6+)
* **Engine / SDK:** Puter.js SDK
* **Libraries:** jsPDF, AutoTable, Tesseract.js (OCR)
